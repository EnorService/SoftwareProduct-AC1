# AC2 — Clientes

Implementar e acompanhar o cadastro de clientes que realizam pedidos.

## Escopo

- Cadastrar cliente com nome, CPF, telefone, e-mail e endereço.
- Listar, pesquisar, editar e visualizar seus dados.
- Inativar clientes relacionados a pedidos para preservar o histórico.

## Critérios de aceite

- [ ] Cadastro, busca, edição e visualização funcionam.
- [ ] Clientes vinculados a pedidos continuam no histórico após inativação.
- [ ] O sistema valida os campos obrigatórios.
